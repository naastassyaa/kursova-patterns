## Sport Booking – інструкція з розгортання

Цей репозиторій містить два окремі проєкти:
- `backend/sport-booking` – Django REST API
- `frontend/sport-booking` – React + TypeScript SPA


## 1. Необхідні інструменти

- **Python 3.11+** 
- **Node.js 18+** (разом з `npm`)
- **Git** (опціонально, якщо клонуватимеш репозиторій, а не просто відкриватимеш папку)

Переконайся, що в консолі працюють команди:

```bash
python --version
npm --version
```

---

## 2. Запуск бекенду (Django)

1. Відкрити термінал у папці `code/backend/sport-booking`:

   ```bash
   cd backend/sport-booking
   ```

2. Створити та активувати віртуальне середовище:

   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

3. Встановити залежності:

   ```bash
   pip install -r requirements.txt
   ```

4. Застосувати міграції:

   ```bash
   cd sportbooking
   python manage.py migrate
   ```

5. (Опційно, але рекомендовано) – залити демо-дані:

   ```bash
   python manage.py seed_demo --force
   ```

   Це створить:
   - центри, зали, секції, тренерів, розклади;
   - абонементи;
   - адміністратора:
     - **логін**: `admin@sportbooking.local`
     - **пароль**: `admin12345`

6. Запустити сервер:

   ```bash
   python manage.py runserver
   ```

   Бекенд буде доступний за адресою: `http://127.0.0.1:8000/`

---

## 3. Запуск фронтенду (React)

1. В іншому терміналі (або новій вкладці) перейти в папку фронту:

   ```bash
   cd frontend/sport-booking
   ```

2. Встановити залежності:

   ```bash
   npm install
   ```

3. Запустити дев-сервер:

   ```bash
   npm start
   ```

4. Відкрити в браузері:
   - `http://localhost:3000/` – головна сторінка застосунку

Фронтенд очікує, що бекенд працює на `http://127.0.0.1:8000/`. Якщо порт або хост потрібно змінити – це робиться у `frontend/sport-booking/src/api/client.ts`.

---

## 4. Авторизація та ролі

- **Адмін**:
  - email: `admin@sportbooking.local`
  - пароль: `admin12345`
  - після входу можна перейти в адмін-панель (кнопка «Адмін панель») і керувати центрами, залами, секціями, розкладами, планами, абонементами та акціями.

- **Звичайний користувач**:
  - можна зареєструватися через форму реєстрації на фронті (`/auth/register`);
  - після реєстрації користувач автоматично логіниться і повертається на головну.

---

## 5. Оновлення демо-даних

Якщо хочеш **повністю перегенерувати** демо-дані (наприклад, після зміни генератора розкладів):

1. Зупини бекенд (`Ctrl+C` у вікні з `runserver`).
2. У терміналі в папці `backend/sport-booking/sportbooking` виконай:

   ```bash
   .venv\Scripts\activate
   python manage.py seed_demo --force
   ```

3. Знову запусти сервер:

   ```bash
   python manage.py runserver
   ```
